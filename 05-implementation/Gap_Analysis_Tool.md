# AS9100 Rev D Gap Analysis Tool

## Instructions

Use this tool to assess your current state of compliance against AS9100 Rev D requirements. For each sub-clause, evaluate your status and note evidence or gaps.

**Status Legend:**
- **FI** = Fully Implemented (evidence exists, process operational)
- **PI** = Partially Implemented (documented but not consistently followed, or gaps in evidence)
- **NS** = Not Started (no documentation or evidence exists)
- **NA** = Not Applicable (justified exclusion documented)
