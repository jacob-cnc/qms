# Quick Start Checklist

## Purpose

This checklist identifies the minimum actions to begin operating under the QMS immediately. Prioritized for maximum audit evidence generation with minimum effort. Start these actions TODAY - every day of records counts toward your 3-month evidence requirement.

---

## Priority Actions

### 1. Post Quality Policy
- **What:** Print QM-002 and post it visibly in the shop work area
- **Form:** QM-002_Quality_Policy.md (print and frame/laminate)
- **Frequency:** One-time, then review annually
- **Why it matters:** Auditor will look for visible policy on arrival. Demonstrates leadership commitment (5.2).

### 2. Start Using Job Travelers
- **What:** Complete QF-004 Job Traveler for every production job. Record each operation, inspection step, and sign-off as work progresses.
- **Form:** QF-004_Job_Traveler.md
- **Frequency:** Every job
- **Why it matters:** Single most important production record. Demonstrates traceability (8.5.2), production control (8.5.1), and release (8.6). Auditors always ask to see these.

### 3. Start FOD Checklist Daily
- **What:** Complete QF-026 at the start of each work day. Walk the shop, check cleanliness, verify no foreign objects in work zones.
- **Form:** QF-026_FOD_Checklist.md
- **Frequency:** Daily (start of shift)
- **Why it matters:** Demonstrates work environment control (7.1.4). Easy to do, generates a stack of evidence quickly.

### 4. Start Calibration Log
- **What:** Enter every measurement tool into QF-020. Record current calibration status, due dates, and any calibration performed.
- **Form:** QF-020_Calibration_Log.md
- **Frequency:** Update when calibrations performed or new equipment added
- **Why it matters:** Calibration is audited heavily. Having a log from day one shows systematic control (7.1.5).

### 5. Start Receiving Inspection Records
- **What:** Complete QF-003 for every incoming material shipment. Check material against PO, verify cert matches, check condition.
- **Form:** QF-003_Receiving_Inspection_Record.md
- **Frequency:** Every receipt of material
- **Why it matters:** Demonstrates external provider control (8.4) and receiving inspection (QP-004). Links material cert to specific stock.

### 6. Begin Filing Material Certs
- **What:** File every material certification (mill test report) received with material. Organize by material type or PO number. Cross-reference to receiving inspection record.
- **Form:** N/A (file supplier-provided documents)
- **Frequency:** Every receipt
- **Why it matters:** Required for traceability. Auditor will trace material cert from finished part back to raw stock.

### 7. Start Tracking OTD and First-Pass Yield
- **What:** Record on-time delivery percentage and first-pass yield (parts right first time, no rework) weekly. Use QF-037 or a simple spreadsheet.
- **Form:** QF-037_Quality_Objectives_Tracker.md
- **Frequency:** Weekly data entry, monthly trend review
- **Why it matters:** Demonstrates monitoring and measurement (9.1). Required input to management review. Shows quality objectives are measurable (6.2).

### 8. Set Up NCR Forms
- **What:** Print blank QF-011 NCR forms and keep them accessible. When any nonconformity occurs (wrong dimension, wrong material, damaged part), fill one out immediately.
- **Form:** QF-011_NCR.md
- **Frequency:** As needed (every nonconformity)
- **Why it matters:** Demonstrates control of nonconforming output (8.7). Auditors expect to see at least one complete NCR cycle.

### 9. Set Up Filing System Per QP-001
- **What:** Create the folder structure defined in QP-001 Document Control. Physical binders or folders for: job packages, material certs, calibration, training, suppliers, audits, management review.
- **Form:** Reference QP-001 for structure
- **Frequency:** One-time setup, then maintain
- **Why it matters:** Records must be retrievable within 24 hours. Organized filing demonstrates document control (7.5).

### 10. Complete Training Self-Assessment
- **What:** Fill out QF-036 Training Matrix for yourself. Identify all competencies required for work you perform. Rate current status. Identify any gaps needing formal training.
- **Form:** QF-036_Training_Matrix.md
- **Frequency:** Initial assessment, then annual review
- **Why it matters:** Demonstrates competence management (7.2). Identifies if any external training is needed before certification audit.

## Weekly Rhythm (Once Established)

| Day | QMS Activity (5-10 min) |
|-----|------------------------|
| Monday | FOD check, review week's jobs for upcoming inspections |
| Tuesday | FOD check, file any material certs received |
| Wednesday | FOD check, update calibration log if any cals performed |
| Thursday | FOD check, update OTD/yield data |
| Friday | FOD check, file completed job travelers, weekly review |

---

## First Month Milestones

- [ ] Quality policy posted
- [ ] Filing system established
- [ ] First 5 job travelers completed and filed
- [ ] First 5 receiving inspections recorded
- [ ] Calibration log started with all active gages
- [ ] 20+ daily FOD checklists filed
- [ ] OTD and yield tracking started
- [ ] At least 1 NCR form completed (self-generate if needed for practice)
- [ ] Training matrix completed for self
