# Drawing Register

## Instructions

This register tracks all customer drawings and specifications received. Update when new drawings are received or revisions are issued. When a new revision supersedes an old one, mark the old entry as "Obsolete" and note the superseding revision. If a job is in progress on a superseded revision, notify per QP-025 Control of Changes.

**Handling New Revisions:**
1. Enter new revision in this register
2. Mark previous revision status as "Obsolete"
3. Record supersedes reference
4. Check if any active jobs reference the old revision
5. If yes - notify customer, hold work pending disposition per QP-025
6. File obsolete drawing in "Obsolete" folder (do not destroy - retain per Record Retention Schedule)

## Storage Method

**Physical drawings:** Filed in labeled hanging folders by customer name, then part number. Active drawings in "Current" drawer, obsolete in "Obsolete" drawer.

**Electronic drawings (PDF):** Stored in computer folder structure: `Drawings/[Customer Name]/[Part Number]/Rev [X]/`. Read-only permissions to prevent accidental modification.

---

## Annual Review

Review this register during management review to:
- Confirm all active drawings match current customer revisions
- Archive/destroy obsolete drawings past retention period
- Verify storage locations are accurate
