## Status Definitions

| Status | Meaning |
|--------|---------|
| In-Cal | Actual calibration/verification completed under QP-010, suitable for intended use and within the assigned interval |
| Unverified | Actual instrument not yet checked/released for acceptance use |
| Example — unverified | Illustrative entry only; ownership, calibration and suitability are not established |
| Example — reference only | Illustrative layout/reference-only entry; not evidence of actual shop equipment |
| Overdue | Past calibration due date - DO NOT USE until recalibrated |
| Out-of-Service | Damaged or retired - segregated from use |
