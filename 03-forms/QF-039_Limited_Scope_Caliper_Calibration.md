## 4. Uncertainty and decision rule — complete before release

Proposed maximum permissible individual indication error E = 0.002 in, or the manufacturer/customer limit if smaller. This is a shop fitness criterion for this loose-tolerance job, not a claim about the unknown caliper model. Record applicable E and source: ______.

Evaluate a conservative expanded uncertainty for a single shop length reading. Include reference certificate uncertainty (u_ref = U_ref/k_ref), resolution (q/√12 for one rounded indication; include additional zero-reading contribution when applicable), repeatability of individual readings (sample standard deviation, not standard error of the mean), thermal effects, reference stack effects where used, alignment/contact effects and residual correction effects. Avoid double-counting; explain correlations or use a conservative sum where independent root-sum-square is not justified. Do not insert zero for an unknown material contribution.

Record B: ______. This 0.005 in bound is 10% of the job's ±0.050 in tolerance; it is a proposed internal capability target, not a customer-imposed rule. If capability cannot be substantiated, use an appropriate external laboratory or alternate qualified instrument.

For production, accept length only when the measured value and ±B lie wholly within 2.950–3.050 in: [2.950+B, 3.050−B]. Record the actual authorized band: ______. Borderline values are HOLD for better measurement, not automatically scrap. Do not accept a part by rounding into this band. This length-only bound does not qualify the tight ID pin method.

## 6. Inspection-session verification log

Before each session: clean/check damage, verify current release and zero, then make three repeated readings of the approved near-3 inch reference. Each error must meet E and must not exceed the maximum error used in released B; repeat range must be ≤0.002 in. If it fails or handling damage is suspected, stop use, quarantine, recalibrate and assess product since last known good check. These checks do not extend the recall date.
