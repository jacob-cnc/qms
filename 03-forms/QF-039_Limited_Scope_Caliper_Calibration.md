## 3. Simple check

1. Clean and inspect the instrument and reference. Let both stabilize in the same shop conditions; avoid heat, dirt, burrs and excessive contact force.
2. Record as-found zero and readings before adjustment. Use representative reference sizes near the intended working size; add points if needed for the authorized range.
3. Take at least three readings per point, releasing and repositioning between readings.
4. Compare each reading with the established reference value and the preselected allowable error. Record any adjustment and repeat the check afterward; retain failed results.
